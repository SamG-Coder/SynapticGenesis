# Saved 411M learning on the selected prose curriculum

Status: CPU preparation checks pass; full-size checkpoint/evaluation preflight
and full curriculum learning have not run. This extends the successful
[411M capacity benchmark](411m-capacity-results.md) to a saved learner and
matched development assessments. The [specification](../data/prose-411m-v1.json)
fixes all settings before execution. The earlier runtime and studies remain
preserved; this experiment selects the validated executable explicitly.

The random founder has 2,048 channels, 8,192 spiking neurons per layer and
eight layers: 411,028,496 parameters and 65,536 spiking neurons. Seed 1337,
learning rate 0.0003, core multiplier one, chunk 128 and scheduled generation
match the completed prose controls. Ordinary stage-balanced replay uses
16,384 descriptors and one replay update per four source observations. That
larger reservoir improved the [completed 2M/105M comparison](prose-replay-capacity-results.md).
No teacher, parent or pretrained weights are imported.

The completed early-width study is also an input, pinned by result hash.
Across seeds 1337, 2027 and 4099, reducing the 27M core rate helped one seed
and worsened two; reducing the 105M core rate helped two and worsened one.
The mean 105M first-stage loss fell from 2.216112 to 2.205320, while the 27M
mean rose from 2.182621 to 2.184875. These exploratory first-stage outcomes
do not establish a 411M rate rule or later retention. This trial therefore
keeps the ordinary rate as an explicit baseline, not an asserted optimum.

## Source and persistence

The existing admitted edition contains 55 training books, 4,817,047 word
occurrences and 26,896,416 bytes. All four curriculum stages are unchanged.
Their endpoints are 8,176, 26,110, 95,207 and 216,289 source observations.
Complete exposure is 27,680,129 source next-byte targets, including the four
foundation passes. Repeated exposure is not additional unique material.
Astronomy, arithmetic and the research-only Physics material are not learned
in this matched prose trial; further source stages require their own explicit
continuation and evaluation.

Periodic saves replace `latest.ckpt` every 8,192 observations; the initial
checkpoint and all four immutable stage checkpoints remain. This interval
changes persistence frequency, not learning updates. A maximal ordinary
checkpoint for this shape and replay capacity is 4,933,292,808 bytes. Admission
reserves eight checkpoint-sized slots, including transactional replacement,
plus 10 GiB of extra disk space. No old checkpoint is deleted.

## Gates before the long run

The native preflight uses a fresh disposable 411M model on the admitted first
source stage. It saves after 128 observations, reloads optimizer and recurrent
state for observation 129, runs two evaluation batches at the original
16-by-128 geometry, and generates 64 bytes through a CUDA graph from the saved
checkpoint. Its four native commands test full-size saving, loading, resumed
computation and evaluation memory. They are not a full-size trajectory-parity
or language-quality test. The existing smaller numerical/restart controls
remain the trajectory evidence.

Source targets are counted from real document boundaries. The first reader
has 14,481 next-byte targets: 113 complete windows and one 17-byte tail.
Consequently the 128/129-observation checks expect 16,273/16,401 source
targets, not simply observations multiplied by 128.

After that preflight passes, declaration authenticates all four preserved
105M checkpoints from the 16,384-slot study. Before any long 411M learning,
40 native assessments through the new executable must reproduce every
previous book result and generated byte exactly. A difference stops the
trial and preserves its outputs. The long run then uses one native live
process; its stage assessments run sequentially after learning finishes.

## Comparison and verification

At each stage, the 411M checkpoint receives the same four validation-book
scores, two early-reader retention scores and four fixed generation prompts.
Each book uses the same 512 sampled 128-byte windows as the baseline, with
strict FP32 and reset recurrent state. Samples use fixed RNG, temperature,
top-k and prompt settings. All six books and raw outputs are retained, along
with the equal-book validation mean and paired differences from 105M.

Actual source/replay/speech counters, source cursor, random states and entire
replay payload must match the corresponding 105M endpoint. Shape-specific
parameters and recurrence differ. Equal exposure does not mean equal wall
time or FLOPs. No reserved test book is scored and no model is promoted as a
teacher or parent by these development measurements.

`large_founder_inputs.py` owns source admission, storage bounds and lightweight
checkpoint facts. `prose_large_founder.py` owns the sequential preflight and
comparison. They reuse `prose_founder.live_arguments`, native command journals
and `checkpoint_assessment` instead of introducing another model path.
The founder helper keeps the earlier argument defaults and accepts an explicit
executable/save interval. Saved-assessment verification similarly accepts an
explicit executable while retaining its old default.

The [host verification](../reports/prose-411m-host.json) checks six unchanged
legacy argument cases, all four actual replay endpoints, first-book tail
arithmetic and 32 rejected policy changes without CUDA work. Existing
assessment-publication checks also preserve an actual ten-command assessment
and reject 14 altered evidence cases. Those tests do not establish full-size
save/load or successful long training.

From the main repository, with the study checkout held fixed and fresh output
paths:

```powershell
python runs/large-prose-founder-worktree/scripts/prose_large_founder.py preflight --out runs/prose-411m-native-preflight-v1
python runs/large-prose-founder-worktree/scripts/prose_large_founder.py declare --out runs/prose-411m-v1 --preflight runs/prose-411m-native-preflight-v1
python runs/large-prose-founder-worktree/scripts/prose_large_founder.py run --out runs/prose-411m-v1
```

All inputs are authenticated before learning and again before completion.
Failures retain their artifacts. One seed and an untuned rate provide a
bounded comparison, not proof of general intelligence, biological development,
useful QA or an optimized model-size ranking.
