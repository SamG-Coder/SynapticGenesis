# Native speed and output demonstration

Measured on 3 October 2026 using the existing C++/CUDA executable, an RTX 5080
(16 GB, driver 616.64), and the ordinary-replay associative model at 190,000
source observations, seed 1337. It has 1,951,624 parameters and 2,048 spiking
neurons across four blocks. The model uses a 256-byte vocabulary: one token is
one byte. These rates are not directly comparable with word-piece token rates.

This is a performance and output demonstration, not a controlled assessment of
learning quality. All six prompts and sampling settings were saved before any
generation. Model computations use the existing native implementation.

| Measurement | Observed result | Boundary |
| --- | --- | --- |
| CUDA graph generation | 6,488 byte tokens/s | Median of seven 1,024-byte rounds after one warm-up |
| Generation without graph capture | 2,005 byte tokens/s | Same checkpoint, prompt, strict FP32, sampling and rounds |
| Graph speedup | 3.24x | All generated bytes identical; final logits and state have zero measured difference |
| Short prompt test | 0.295–0.318 seconds for 192 generated bytes | Whole native process, including launch, loading, prompt processing and output; files may be cached |
| Live learning | 35,881 new-source byte targets/s | Includes replay, periodic generation, logging and checkpoint saves in the native loop |

Resident generation includes CPU sampling, transfers, model execution and
synchronization. It excludes model loading, graph capture, prompt processing
and console/file output. Graph capture itself took 43.1 ms. Other desktop GPU
contexts were active; this is one run on one device, not a cross-device result.

The learning demonstration continued an independent copy for 4,096 new-source
observations and 1,024 replay updates. It processed 500,571 new-source targets
and 103,947 replay targets in 13.951 seconds, and generated 768 bytes at the
existing speech intervals. Source learning and speech share mutable weights
and persistent recurrent state. They alternate at completed update boundaries.
Generated text never becomes its own training target. The original checkpoint
remained unchanged. No held-out tests were scored.

context, generating 192 bytes. The complete unedited outputs are retained in

The native runtime works and produces text quickly. Reliable question answering
and coherent prose remain unproven. One correct location word is insufficient:
the paired question shows the answer failing to follow the changed context.
The model is a continuation learner, without established instruction-following
ability. These examples are a direct display of current behavior rather than a
comprehensive capability benchmark.

## Reproduce

```powershell
python scripts/native_demonstration.py --out runs/native-demonstration-new
```

This requires the local learned ancestors, prepared early-reader edition and
curriculum from the completed retention study; their checkpoint binaries and
prepared data are not bundled in Git. The script authenticates the ancestor
and curriculum against that study, records commands before execution, saves
all six raw samples, measures decode and runs one bounded live continuation.
It does not train on the questions. The new reading stage uses the selected
ten-story training edition with its existing attribution; development and test
stories are excluded. The full report retains executable/checkpoint hashes,
per-round timings, settings, all outputs and native live-session counters.
