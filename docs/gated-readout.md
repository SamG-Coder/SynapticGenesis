# Input-dependent trace readout experiment

The [optimization controls](binding-optimization.md) showed that existing cells can fit one complete binding group, but increasing their later-stage learning rate does not solve the full collection. The optional `--cell gated` tests a learned read coefficient over each neuron's stored spike trace. The current normalized block input controls that coefficient; the gate does not have labels, object IDs, predefined associations or a separate answer lookup table.

The [architecture equations](architecture.md#input-dependent-trace-readout) describe its input-dependent multiplication and initialization. Gate weights start at zero, giving a read coefficient of one. At equal width and seed, its initial forward function and common parameters match the ordinary trace cell. This is an experiment inspired by input-dependent selection in [Mamba](https://arxiv.org/abs/2312.00752), not an implementation of that architecture.

## Matched exposure and capacity controls

Every model starts from scratch on the unchanged binding-v2 reading/prerequisite/binding curriculum, using seed 1337, the original learning rates, answer emphasis and replay policy. Each completes 34,000 live observations, 8,500 replay updates and 6,528 generated bytes. No test-partition evaluation is performed. The common initial parameters of the 512-neuron trace and gated models are verified byte-identical.

| Cell | Neurons per block | Parameters | Complete development groups | Earlier-reader loss | Graph decode, microseconds/byte |

| Trace | 512 | 1,190,400 | 0 / 144 | 2.68424 | 147.33 |
| Gated | 344 | 1,197,280 | 0 / 144 | 2.65953 | 175.76 |
| Gated | 512 | 1,716,736 | 1 / 144 | 2.57767 | 161.77 |
| Trace capacity control | 768 | 1,718,784 | 1 / 144 | 2.66112 | 150.25 |

All use 256 channels and four blocks. The 344-neuron gated model approximately matches the default trace parameter budget. The 768-neuron trace model approximately matches the larger gated budget. Changing width also changes initialization and recurrent-state capacity, so these are useful controls rather than identical models with one intervention.

The larger gated model has lower earlier-reader loss than the similarly sized trace control in this one-seed experiment. Its full live loop is slower: 77.15 versus 52.72 seconds. Neither solves the binding task. Training-partition complete groups also remain between zero and 0.23%, so this is not only a held-out generalization failure. The result does not justify promoting the gate to the default or claiming general retrieval competence. [Full language and timing evidence](../reports/gated-binding.json).

Decode timing uses seven 1,024-byte rounds after warmup, with strict FP32 and alternating regular/graph order. It includes host sampling, transfers and synchronization, and excludes capture and prompt setup. Graph and regular generated bytes, final logits and state agree exactly. Live-loop timing includes replay, speech, logging and stage/checkpoint I/O, excluding model setup and initial/final validation. These are local RTX 5080 measurements, not energy measurements or a general architecture ranking.

## Recall and lifecycle checks

Six disposable cue models, with 64 channels, 88 neurons, two blocks and 68,016 parameters, reached 100% one-bit recall at 128- and 256-byte delays across three seeds. Clearing all recurrent state returns them to exactly 50%; clearing only the trace reduces accuracy to 45.95–56.84%. This retains the earlier narrow memory capability with a similar parameter budget, but uses different width and adds time. These models never supply language-model or population weights. [Cue results](../reports/gated-cue.json).

All eleven native suites pass. The independent nonzero-gate CPU fixture exercises both input-gradient paths, signed incoming state, activity regularization and Adam updates. Maximum plain-gradient error is 2.99e-8; weighted-target gradient error is 6.71e-8. Identity-gate output matches the trace cell; disabling trace gain recovers LIF within the tested tolerance.

The curriculum CLI covers 93 native invocations, including 24 ordinary and eight answer-emphasized restart cases across all four cells with optional SI. Maximum complete-state discrepancy is 1.50e-8 and generated bytes match. Separate probe tests check CPU score/greedy agreement and reject ternary/paging modes for continuous emissions. Batch prefix-policy persistence and explicit overrides also pass for all cells.

Population checks cover inherited nonzero gate weights, function-preserving width growth, learning by new neurons, exact buffer accounting, canonical live checkpoints, resource-limited births, stricter selection under scarcity and old-age death. Dead members cannot resume population learning. The default cell and established lifespan rules remain unchanged. [Numerical and lifecycle evidence](../reports/gated-validation.json).
